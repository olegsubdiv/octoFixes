# Решения

## 2026-10-17 — единый octoFixes

Пользователь поручил объединить свои фиксы, сделать публичный GitHub-проект и
публиковать готовые обновления в Releases. Название octoFixes выбрано пользователем.

В один мод входят оба проекта (ME 1.1.1 + Hextech 1.1.1), включая последнюю
визуальную поправку автоплея форм. Неподтверждённый Evolution-баг не включён.
Namespace модулей сохранены, но игровая точка запуска, DLL и манифест общие.
Патчи модулей ставятся отдельно с разными Harmony ID.

Сборка и проверки локальные: нужны закрытые DLL установленной игры/Workshop.
В GitHub публикуются только собственный код, документация и готовый пакет фикса.
Стабильный asset octoFixes.zip позволяет использовать releases/latest/download.
Установщик переносит старые отдельные моды в резервную копию вне mods.
