## Вылет на Tempest / Dark Magician — 2026-10-18

Пользователь попросил проверить вылет во время каста. Последняя карта в логе —
TEMPEST, ранее в том же бою разыгран THEHEROEXPANSION-DARK_MAGICIAN.
TheHeroExpansion.DarkMagicianPatch.OrbChannelPatch.Postfix использует
Task.ContinueWith(... OrbCmd.Channel<DarkOrb> ...).Unwrap() без игрового scheduler;
стек ошибок прямо показывает выполнение этой continuation в ThreadPool.
Далее Godot пишет об обращениях к NOrbManager/PlayEvokeSfx вне главного потока.
Windows Application 1000/1001: вылет 00:07:31, ntdll.dll, 0xc0000374 (heap corruption).
Ошибка фоновой работы со сценой подтверждена; связь с нативным вылетом очень
вероятна, но дамп не разобран. Связь с фиксом Void Form не обнаружена.
Снимок предыдущей сессии и декомпиляция установленного DarkMagicianPatch:
diagnostics/crash-2026-10-18 (локально, не публиковать).
Игра уже перезапущена; установленная octoFixes 1.0.2 не менялась.
Патч этой ошибки ещё не реализован. Возможное исправление: заменить опасный
postfix на последовательный await с сохранением игрового SynchronizationContext
и распространением ошибок исходной операции, сохранив ровно одну бонусную сферу.

## Void Form завершала ход при стартовом автоигрывании — 2026-10-17

Причина подтверждена по установленным DLL: VoidForm.OnPlay вызывает PlayerCmd.EndTurn;
родной AutoPlayFormsAtCombatStartRuneBase оборачивает автоигру в
HextechFormAutoPlayHooks.BeginEndTurnSuppression, а наша замена потеряла эту обёртку.
В логе текущего рана есть стартовое автоигрывание VOID_FORM нашим модулем.
Снимок лога и декомпиляция только локально: diagnostics/voidform-current.
Версия 1.0.2 восстанавливает родной IDisposable/AsyncLocal scope вокруг каждого
авторозыгрыша формы. Метод проверяется до отключения родных обработчиков;
ручной розыгрыш и обычное завершение хода вне scope сохраняются.
build.ps1 -Zip прошёл без предупреждений/ошибок, обе группы тестов PASS.
Регрессия вызывает настоящий PlayerCmd.EndTurn под родным Harmony-prefix:
внутри scope команда подавлена; проверены await, вложенность, исключение и
изоляция параллельного вызывающего кода, восстановление завершения хода снаружи.
Реальный повтор боя в коопе ещё не проверен. Релиз v1.0.2 опубликован:
https://github.com/olegsubdiv/octoFixes/releases/tag/v1.0.2.
Архив по latest-ссылке скачан и сверен с проверенной сборкой (SHA256
8afa8e2b2ebfa5ff0e7fad1df62599051af78b2cd32a9254d052734c42fcb410).
После сообщения пользователя о закрытии игры установлена 1.0.2 из проверенного
релизного ZIP; установленная DLL и JSON совпали с пакетом по SHA256.
Предыдущая версия сохранена в папке игры:
octoFixes-backups/20261017-230252-0d0b78b6e2df467d9206e6175d3cc26b.
