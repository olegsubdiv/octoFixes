## История отдельных фиксов

Обновление 2026-10-09: MultiEnchantmentCoopFix v1.1.1.

По просьбе пользователя исправлен рассинхрон checksum 342 после Primal Force:
у клиента Giant Rock без зачарования сериализовал MultiEnchantmentOrderData=[SPIRAL],
у хоста поле отсутствовало. Лог и подробный разбор — в diagnostics/.

SerializationPatches удаляет валидную историю, когда нет основного и дополнительных
зачарований. Учитывается также сериализованное основное зачарование как страховка.
Настоящие дополнительные зачарования, остальные свойства и некорректный JSON сохраняются.
Runtime-состояние исходного мода не меняется; нормализуется только сериализованный результат.

Сборка и 35 проверок на типах установленной sts2.dll прошли, без предупреждений компилятора.
Есть регрессия по дампу Giant Rock: после очистки JSON полезной нагрузки хоста/клиента совпадает.
Реальный повтор боя в двух игровых клиентах ещё не проверен.

Для применения обоим игрокам нужна v1.1.1 и полный перезапуск игры.
Локально установлена v1.1.1 в F:/SteamLibrary/steamapps/common/Slay the Spire 2/mods/MultiEnchantmentCoopFix;
SHA256 установленной DLL совпал со сборкой. Предыдущие DLL/манифест сохранены в
diagnostics/installed-1.1.0-backup. Архив для второго игрока: dist/MultiEnchantmentCoopFix-1.1.1.zip.
HextechFormRuneCoopFix не менялся. Каталог проекта не является git-репозиторием.
